### 3.2 Bug fixes (real bugs, not just tuning)

**Bug A — Form section header stuck on "Rechteck"** (`2b54e64a`, task 107)
- `index.html` ships hardcoded defaults: `<span id="val-shape">Rechteck</span>`

**Bug B — `HIDE_LEGS_BY_SHAPE_LENGTH` cleared** (`80923bd1`, task 108)
- Previous session filtered problem combinations out of the leg picker
- User asked to show all legs on all shapes and rely on positioning offsets instead
- **Fix**: `HIDE_LEGS_BY_SHAPE_LENGTH = {};` (empty). Location around line 3844 in app.js.

**Bug C — `switchLeg` didn't call `applyDimensions`** (`bf35a6ea`, task 112 — the main root-cause of this session)
- When user clicked a different leg in the picker, `switchLeg(index)` made the leg visible at its GLB-baked position (~240cm baseline) but never re-ran positioning
- Reload worked because `loadModel` called `applyDimensions` once on load, positioning all legs (visible or not)
- **Fix**: added `this.applyDimensions();` at end of `switchLeg` (around line 2427). In build `4fb1728a` added three additional safety timers at 50/250/800ms.

**Bug D — safety timers after shape switch** (`56394aa1`, task 111)
- External legs (Halbrunde, Butterfly, U, Drone) load asynchronously and schedule their own debounced applyDimensions at ~60ms
- Fast shape switches could cancel those timers before external legs arrived
- **Fix**: `loadModel` schedules additional applyDimensions at 300ms and 700ms (see `_safetyApplyDimTimer1/2`).

### 3.3 Current per-shape offsets for Satz legs

Location: `configurator/js/app.js`, function `getLegEdgeDistance(lengthCm, shapeId)` starting around line 2175.

```javascript
// Base distances by length
if (lengthCm <= 200) dist = 30;
else if (lengthCm <= 260) dist = 40;
else if (lengthCm <= 280) dist = 50;
else if (lengthCm <= 300) dist = 60;
else if (lengthCm <= 350) dist = 70;
else dist = 75;

// Per-shape offsets
if (shapeId === 'round') {
  if (lengthCm <= 100) dist += 13;
  else if (lengthCm <= 110) dist += 10;
  else if (lengthCm <= 120) dist += 9;
  else if (lengthCm <= 130) dist += 7;
  else if (lengthCm <= 140) dist += 6;
} else if (shapeId === 'verbaan') {
  // no offset
} else if (shapeId === 'danish-oval' || shapeId === 'halboval') {
  if (lengthCm <= 180) dist += 20;
  else if (lengthCm <= 200) dist += 12;
  else if (lengthCm <= 220) dist += 8;
  else if (lengthCm <= 240) dist += 6;
  else if (lengthCm <= 260) dist += 4;
} else if (shapeId === 'oval') {
  if (lengthCm <= 160) dist += 25;
  else if (lengthCm <= 180) dist += 20;
  else if (lengthCm <= 200) dist += 12;
  else if (lengthCm <= 220) dist += 6;
} else if (shapeId === 'organic') {
  if (lengthCm <= 200) dist += 20;
  else if (lengthCm <= 220) dist += 10;
  else if (lengthCm <= 240) dist += 5;
} else if (shapeId === 'halfrond') {
  if (lengthCm <= 180) dist += 20;
  else if (lengthCm <= 200) dist += 12;
  else if (lengthCm <= 220) dist += 6;
} else if (shapeId === 'bootsform') {
  if (lengthCm <= 180) dist += 12;
  else if (lengthCm <= 200) dist += 6;
}
```

**Formula the code uses to position legs**:
```
defaultTargetOuter = defaultLength / 2 - defaultEdgeDist   // cm from center
currentTargetOuter = currentLength / 2 - currentEdgeDist
spreadShiftCm      = currentTargetOuter - defaultTargetOuter
```
The shift moves the left/right split halves of a Satz leg inward or outward relative to their baked GLB position.

Interpretation for Halboval 180 (with the +20 offset above):
- currentEdgeDist = 30 + 20 = 50 cm
- currentTargetOuter = 90 − 50 = 40 cm — this is the leg's INNER-edge target (leg outer tip lands ~10cm further out, so ±0.50m world X, verified via browser measurement)

## Addendum 2026-08-19 — performance pass (build `d271ce29`)

- **All GLBs are now Draco-compressed** (`KHR_draco_mesh_compression`, positions 16-bit, normals 12-bit) and pruned of
  unreferenced meshes (Butterfly leg file contained the whole rectangle table; Bootsform carried 206 unused meshes).
  120 MB → ~5 MB. Decoder is self-hosted at `configurator/js/draco/` (from three 0.162.0) and wired in `app.js`
  (`DRACOLoader` → `loader.setDRACOLoader`). **Re-export workflow for new/updated GLBs:** drop the raw file in place, then run
  `gltf-transform prune --keep-leaves --keep-attributes ... && gltf-transform draco ...` (see git history of this commit for the exact
  node script) — or just push the raw file; it still loads, only slower.
- Originals of every GLB are in git history at commit `a3704c7`.
- Leg/edge/shape swatch PNGs downscaled to ≤400 px (display size is 56 px): 83 MB → 4 MB. Names unchanged.
- `model-viewer` CDN script removed (unused). `modulepreload` for three + addons, `preconnect` for fonts.gstatic/jsdelivr.
- `preloadAllModels()` (parse-all-shapes-into-RAM) now desktop-only + Save-Data aware; phones keep the network-only prefetch.
- `zw-products*.json` no longer busts the cache with `Date.now()` — server sends `no-cache` → ETag revalidation, still always fresh.
- `renderLegGrid()` skips the `innerHTML` swap when markup is unchanged (was re-created on every slider move).
- Ceramic textures moved `textures__1/ceramic` → `textures/ceramic` (config.js pointed at the latter — all 21 were 404).
  The two 6 MB RGBA PNGs (jade, fior-di-bosco) converted to JPG.
- `server.js`: repo root is no longer served publicly (was exposing server.js, CSVs, HANDOFF, zips). Only `configurator/`
  (mounted at `/` and `/configurator`) and `glb files tables and legs/` are reachable. GLBs: `max-age=1y, immutable`.
- `.railwayignore` no longer excludes the GLB folder. Backup JS files removed (in git history).
